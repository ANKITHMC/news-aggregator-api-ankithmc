# News Aggregator API

A backend REST API built using Node.js, Express, and MongoDB that allows users to register, login, set news preferences, and fetch personalized news using an external News API.

---

# Features
- User Registration & Login (JWT Authentication)
- Update and fetch user news preferences
- Fetch personalized news based on preferences
- Secure protected routes using JWT
- Input validation and error handling

---

# Tech Stack
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication
- Axios (External News API)
